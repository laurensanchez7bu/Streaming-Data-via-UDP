These are reference implementations that you can use to test your own code. Note that the jsonl file must be in the same directory that you are running the command from! If you're executing from a different directory, you can either copy the jsonl file to your local directory, or you can chain a `cd` command as follows:

`cd [PATH]/reference_implementations && ./server`

You don't need to be in any particular directory to run the client. Simply run:

`[PATH]/reference_implementations/client [SERVER_IP_ADDRESS:PORT]`
